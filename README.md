### ⚡ [Agentic AI Image Studio](https://github.com/SAURABHSALVE/image-generation) — Latency-First Design

> **Multi-agent system for automated prompt refinement & output control**

<details open>
<summary><b>💡 Explicit Tradeoff</b></summary>

**Why this matters:** Real products value **speed and reliability**, not perfect outputs.

**Tech Stack:** `PyTorch` `Diffusers` `Agent Orchestration`
